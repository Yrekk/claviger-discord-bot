# Manifest du pack de préparation d'arborescence

Ce pack est conçu pour être extrait à la racine du dépôt Claviger.

## Ce qu'il contient

- des `README.md` pédagogiques pour les dossiers actuels et les sous-dossiers cibles ;
- le mode opératoire de collaboration mis à jour ;
- l'arborescence cible de fin de V1.1 ;
- un prompt prêt à être utilisé pour la future migration.

## Ce qu'il ne contient PAS

- aucun fichier Python ;
- aucun fichier de test Python ;
- aucun déplacement de code ;
- aucun `__init__.py` nouveau ;
- aucune modification de schéma ;
- aucune modification fonctionnelle ;
- aucun remplacement du `README.md` principal.

Les nouveaux dossiers sont matérialisés par leurs README.

## Pourquoi le README principal n'est pas inclus

La nouvelle arborescence n'est pas encore appliquée.

Modifier maintenant le README principal ferait courir le risque de décrire une structure future comme si elle était déjà effective.

Il devra être mis à jour à la fin de la migration réelle.
