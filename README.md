# Claviger

Claviger is a Discord bot for consent-based and preference-driven role and channel access management.

## Project status

Initial project setup.

## Planned features

- Rule acceptance workflow
- Preference-based access selection
- Composite Discord role calculation
- Automatic role synchronization
- Self-service access removal
- Administrative diagnostics
- Minimal permission requirements

## Security principles

- No Discord administrator permission
- No message content access
- Secrets excluded from version control
- Minimal collection of personal data
- Access roles used as the primary source of truth
