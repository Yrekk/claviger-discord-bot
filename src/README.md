# Code source

Le dossier `src/` contient le code installable de l'application.

Claviger utilise un *src layout* : le package Python réel se trouve dans `src/claviger/`.

Cette organisation sépare clairement :

- le code applicatif ;
- les tests ;
- la documentation ;
- les fichiers de configuration et de déploiement.

Le code importable ne doit pas être dispersé à la racine du dépôt.
