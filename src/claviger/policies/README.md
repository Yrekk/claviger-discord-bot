# Policies

Une **policy** exprime une règle de configuration ou de comportement applicable à une guild.

Elle répond à des questions telles que :

- quel rôle est attendu ;
- quelle fonctionnalité est activée ;
- quelle convention doit être appliquée ;
- quel comportement restrictif utiliser lorsqu'une configuration manque.

Les policies permettent d'éviter de disperser des constantes spécifiques à un serveur dans les commandes et services.

Elles ne remplacent pas l'autorisation runtime ni les contrôles de permissions Discord.
