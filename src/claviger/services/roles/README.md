# Services liés aux rôles

Services génériques qui découvrent, classifient, valident ou manipulent les rôles Discord.

Les règles de hiérarchie et de manageability doivent rester centralisées ici lorsqu'elles sont génériques.

Les planners/executors propres à un workflow appartiennent au domaine `workflows/`, même s'ils produisent des mutations de rôles.
