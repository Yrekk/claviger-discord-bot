# Services de catalogues

Services responsables de la découverte, classification, synchronisation et coordination des catalogues.

Un catalogue relie les ressources Discord réellement disponibles aux choix configurables exposés par Claviger.

Les services de catalogues doivent préserver la distinction entre :

- données observées sur Discord ;
- métadonnées configurées par l'humain ;
- état de synchronisation.
