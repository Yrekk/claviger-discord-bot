# Models de catalogues

Modèles utilisés pour représenter les catalogues, leur synchronisation, leurs variantes et les associations rôle ↔ salon.

Un catalogue décrit les options configurables ou découvertes par Claviger.

Ces modèles permettent de séparer la représentation des données de la logique qui les découvre, les synchronise ou les affiche.
