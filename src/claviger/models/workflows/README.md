# Models de workflows

Modèles décrivant les définitions, configurations, questionnaires et structures nécessaires aux workflows.

Un workflow représente un parcours configurable qui transforme un contexte et des choix en comportement applicatif.

Ces modèles doivent rester indépendants autant que possible de la présentation Discord afin d'être réutilisables par d'autres interfaces.
