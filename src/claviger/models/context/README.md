# Models de contexte

Modèles décrivant les capacités, questions et contextes résolus utilisés par les workflows.

Le contexte sert à représenter les informations nécessaires à l'exécution ou à la configuration d'un workflow sans coupler ce dernier directement à une interface particulière.
