# Commandes générales

Ce sous-dossier regroupe les commandes publiques simples qui ne relèvent ni de l'administration ni d'un workflow configurable complet.

Une commande n'entre ici que si elle reste suffisamment autonome et légère.

Ce dossier ne doit pas devenir un emplacement par défaut pour toute commande difficile à classer.
